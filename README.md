# Campus Record — Student Database Management

A responsive college student directory for recording student details and reviewing enrollment by department, section, and gender.

## Run the project

Open `index.html` in a modern browser. No installation or build step is needed.

## Features

- Add, view, edit, and delete student records.
- Record student ID/admission number, name, gender, department, section, year/semester, date of birth, email, phone, and address.
- Dashboard totals for all students, male students, female students, departments, and unique department sections.
- Department enrollment overview and gender distribution, including the "Other" category.
- Search by name, ID, department, section, or email; filter by department and gender.
- Export the full student directory as a CSV file.
- Persist records in browser local storage.

## Data storage

This standalone version stores records in the browser that opened the app. Data is not synchronized with other devices or browsers. Export a CSV backup when needed; clearing the browser's site data removes the saved records.
